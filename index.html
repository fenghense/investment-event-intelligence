关于本项目

Investment Event Intelligence 是一个基于 AI 的投资事件情报产品，旨在帮助用户看清同一投资事件在不同信息源中的演化脉络。

技术架构

  • 后端 AI 工作流：基于扣子(Coze) 平台可视化编排
  • 前端：原生 HTML5 + CSS3 + JavaScript
  • 数据接口：扣子 API (REST) + 扶摇 API + iFinD MCP
  • 部署：GitHub Pages / Vercel / Netlify

核心能力

  • 同一事件的识别、合并与版本演化
  • 事实、观点、推测和传闻的区分及证据权重
  • 事件发生时间、披露时间、抓取时间和更新时间的处理
  • 更新、否认、更正、过期时自动改变结论并通知用户

数据源

  • 扶摇：行情、财务、估值、特色数据
  • iFinD MCP：公司公告、新闻、研报、互动与行业资讯
  • 公开权威材料：政府公告、交易所公告、权威媒体（fallback）
